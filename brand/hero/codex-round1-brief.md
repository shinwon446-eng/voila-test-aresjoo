# 히어로 배너 1차: 참고 영상 비평과 시안 비판

첨부 그림 넷.
1. 참고 영상의 한 장면(공들이 다 나온 뒤)
2. 참고 영상의 다른 장면(되감긴 직후, 카드가 겹쳐 있는 상태)
3. 우리 홈 화면(PC)
4. 우리 홈 화면(휴대폰)

참고 영상은 다른 서비스의 가로 띠 배너다(약 8:1, 5.9초 반복). 밝은 종이 바탕, 둥근 테두리 선, 붓글씨 빨강 "Catch'em" 과 굵은 검정 "ALL", 알약 "UNBOX POKEMON", 비스듬한 남색 판 위에 카드 석 장이 부채처럼 펼쳐지고, 공들이 작게 나타나 커지며 떠다닌다.

우리 서비스: voila.gg. 박스를 열면 실물 상품이나 USDT 가 나온다. 화면은 검은 바탕(#000), 흰 글자, 강조색 샴페인(#d9c39a) 하나, 장식이 거의 없다(그림 3, 4).
파운더의 주문: **홈 맨 위에 "가입하면 포켓몬 카드 박스를 준다"는 히어로 배너. 움직이는 것. 참고 영상보다 디자인과 움직임이 확실히 더 좋을 것.**

## 넘을 수 없는 선
- 포켓몬 캐릭터 그림, 실제 카드 그림, 몬스터볼 모양, 포켓몬 로고와 "Catch 'em all" 문구는 쓰지 않는다(남의 저작물과 상표다). "포켓몬 카드 박스"라는 상품 이름을 글로 적는 것만 된다.
- 그림 파일과 외부 라이브러리 없이 CSS 와 SVG, 약간의 React 로만 만든다(Next.js 정적 사이트). 움직임은 transform 과 opacity 위주, 60fps.
- 움직임 줄이기 설정을 켠 사람에게는 멈춘 한 장면을 보여 준다.
- 글은 한국어, 영어, 중국어 세 가지로 들어간다(길이가 다르다). 가장 좁은 휴대폰 폭은 320px.
- 가짜 숫자, 남은 시간 재촉, 남이 당첨됐다는 소식은 쓰지 않는다.

## Claude 의 시안 (비판할 대상)
이름 "꺼내는 순간". 검은 바탕의 둥근 판(반경 26) 하나.
- 왼쪽: 작은 글 "신규 가입 혜택", 제목 "가입하면 포켓몬 카드 박스 하나", 흰 알약 단추 "가입하고 받기".
- 오른쪽: 입체 장면. 우리 개봉 화면에 쓰는 봉인 상자(CSS 로 만든 여섯 면)가 살짝 내려앉았다가 뚜껑이 넘어가고, 그 안에서 홀로그램 카드 석 장이 솟아올라 부채처럼 펼쳐진다. 카드는 캐릭터 없이 박(箔) 무늬와 빛만 있다. 펼쳐진 뒤 빛줄기가 카드 면을 한 번 훑고, 작은 빛 조각들이 천천히 떠오른다. 6초쯤 머문 뒤 조용히 접혀 다시 시작한다.
- PC 에서는 마우스 위치에 따라 카드와 상자가 살짝 기운다.
- 휴대폰: 글이 위, 장면이 아래(또는 장면을 오른쪽에 작게).

## 답할 것 (한국어, 짧게, 줄표와 가운뎃점 없이)
1. 참고 영상에서 실제로 잘한 것 셋과 못한 것 셋. 우리가 이겨야 할 지점이 어디인가.
2. Claude 시안의 약점을 냉정하게. 특히 캐릭터 그림 없이도 "포켓몬 카드"로 읽히는가, 검은 화면에서 밋밋하지 않은가, 8:1 띠가 아닌 판 모양이 맞는가.
3. 네가 생각하는 더 나은 안 하나(또는 시안을 고친 안). 장면 구성과, 시간표를 ms 단위로: 무엇이 언제 어떤 가속으로 움직이는가. 카드의 박 무늬를 CSS 로 어떻게 내는지도 구체적으로(그라디언트 종류, 겹, 섞기 방식).
4. 휴대폰 320px 에서의 배치.
5. 만들 때 조심할 것 셋(성능, 접근성, 글 길이).
