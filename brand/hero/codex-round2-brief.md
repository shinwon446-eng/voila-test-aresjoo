# 히어로 배너 2차: 만든 것을 화면으로 비판

첨부 그림 셋.
1. 우리 배너의 PC 화면을 시간 순서로 찍은 것(왼쪽 위부터 0ms, 900ms, 1250ms, 1450ms, 1800ms, 2400ms, 2700ms, 6800ms). 배너 크기 1120×292.
2. 같은 배너의 휴대폰 화면(폭 390). 배너 크기 358×387.
3. 참고 영상의 한 장면(이겨야 할 상대).

네 1차 비평에서 받아들인 것: 제목을 상품명으로 크게, 설명 "가입하면 하나를 받습니다", 작은 라벨 삭제, 뒤를 받치는 비스듬한 판, 되감지 않고 장면을 사라지게 한 뒤 다시 시작, 멈춤 단추, 화면 밖에서 멈춤, 움직임 줄이기에서는 펼쳐진 한 장면.
받아들이지 않은 것: "상자를 열지 말고 카드 한 장만 조용히". 파운더의 주문이 참고 영상보다 움직임이 확실히 더 좋은 것이라서, 상자가 열리고 카드 석 장이 솟아 펼쳐지는 장면을 유지했다. 카드는 은빛 바탕에 다섯 색 박(홀로그램)이 천천히 돈다. 은빛과 샴페인만으로는 화면이 죽어 보여서 색을 넣었다.

한 바퀴: 닫힌 상자 700ms → 웅크림 420ms → 뚜껑이 넘어가고 카드 석 장이 솟아 펼쳐짐(0.82초, 긴 감속) → 빛이 카드를 차례로 훑음 → 약 4.7초 머묾(카드가 아주 조금 떠 있고 빛 조각이 깜빡임) → 0.5초에 걸쳐 장면이 사라짐 → 처음으로.

## 답할 것 (한국어, 짧게, 줄표와 가운뎃점 없이. 칭찬은 한 줄만)
1. 참고 영상과 나란히 놓았을 때 우리가 지는 점을 큰 것부터 다섯. 화면에서 보이는 것만 근거로 든다(몇 ms 장면의 어느 부분인지 짚는다).
2. PC 화면의 구도 문제: 빈 곳, 크기, 균형. 장면과 글의 크기를 얼마로 바꿔야 하는가(px 나 배율로).
3. 휴대폰 화면의 문제. 배너 높이 387px 가 과한가. 과하다면 어디를 줄이는가.
4. 움직임에서 고칠 것: 어느 구간이 밋밋하거나 과한가. 더 좋게 만들 장치 두 개까지(구체적으로, transform 과 opacity 로 되는 것만).
5. 카드가 "수집 카드"로 읽히는가. 더 그렇게 보이려면 카드 면의 무엇을 바꾸는가(캐릭터 그림과 남의 상표 없이).
6. 이대로 내보내도 되는가. 안 된다면 반드시 고칠 것 셋.
