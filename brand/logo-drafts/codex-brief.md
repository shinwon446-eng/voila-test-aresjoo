# VOILA 로고 시안 의뢰 (Codex 몫: 시안 D, E, F)

너는 브랜드 디자이너다. 아래 서비스의 로고 시안 **셋**을 SVG 로 만들어 파일로 저장한다. 다른 파일은 건드리지 않는다.

## 서비스
- 이름 VOILA, 주소 voila.gg. 프랑스어 "voilà"(자, 여기 있습니다)에서 왔다.
- USDT 로 박스를 열면 실물 상품이나 USDT 가 나오는 서비스다. 핵심 순간은 "열어서 드러나는 순간"이다.
- 화면은 검은 바탕(#000)에 흰 글자, 장식이 거의 없는 차분한 화면이다(ChatGPT 앱과 비슷한 절제). 강조색은 샴페인(#d9c39a) 하나뿐이고 아주 조금만 쓴다.
- 로고는 화면 왼쪽 위에 높이 24~28px 로 들어간다. 그 크기에서 또렷해야 한다.
- 지금 로고: 굵은 산세리프 "VOILA" 뒤에 샴페인색 네 꼭지 별 하나. 파운더가 마음에 들어 하지 않는다(평범하다).

## 다른 디자이너(Claude)가 맡은 방향: 겹치지 않게 피한다
- A: O 의 윗부분이 뚜껑처럼 들린 워드마크
- B: À 의 억음 부호를 강조색으로 쓴 가는 대문자 워드마크
- C: 소문자 voila.gg, 점만 강조색

## 네가 만들 것
서로 분명히 다른 방향 셋. 예를 들면 심벌(아이콘)이 앞에 붙는 형태, 글자 사이의 공간을 쓰는 형태, 글자 하나를 박스나 빛으로 바꾼 형태. 예시를 그대로 따르지 말고 네 판단으로 정한다.

시안마다 파일 둘:
- `brand/logo-drafts/d-logo.svg`, `e-logo.svg`, `f-logo.svg`: 가로형 로고(머리글 자리에 들어가는 것)
- `brand/logo-drafts/d-icon.svg`, `e-icon.svg`, `f-icon.svg`: 정사각 아이콘(파비콘, 앱 아이콘 자리). viewBox `0 0 64 64`, 바탕 없음

## 지킬 것 (어기면 쓸 수 없다)
1. `<text>` 와 글꼴을 쓰지 않는다. 글자는 전부 `<path>`, `<rect>`, `<circle>`, `<polygon>`, `<line>` 같은 도형으로 직접 그린다. 외부 파일, `<image>`, `<filter>`, 그라디언트, 스크립트 없음.
2. 색은 둘뿐: 본체는 `fill="currentColor"` 또는 `stroke="currentColor"`, 강조는 `#d9c39a`. 강조색 없이 한 색으로만 찍어도 로고로 읽혀야 한다.
3. 가로형 로고의 viewBox 높이는 64 로 맞춘다(폭은 자유, 대략 200~360). 여백 없이 꽉 채우지 말고 위아래 8 정도 숨을 둔다.
4. 높이 24px 로 줄였을 때 "VOILA" 로 읽혀야 한다. 가는 선(64 높이에서 굵기 4 미만)과 작은 장식은 쓰지 않는다.
5. 글자의 굵기, 높이, 간격이 눈으로 보기에 고르게 맞아야 한다. V 와 A 는 같은 기울기를 쓴다.
6. 다른 회사 로고를 닮지 않게 한다. 왕관, 보석, 선물 리본, 주사위, 슬롯 같은 흔한 도박과 선물 상징은 쓰지 않는다.
7. 파일은 사람이 읽을 수 있게 들여쓰기하고, 맨 위에 한 줄 주석으로 시안 이름을 적는다.
