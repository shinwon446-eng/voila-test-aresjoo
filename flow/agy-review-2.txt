### 1. 320, 390, 768, 900, 1440 폭에서의 배치

1. **320px 폭(초소형 모바일)**
   - **머리줄 충돌 및 넘침 위험** (`web/components/shell/AppShell.tsx` 48-56줄, `web/app/ui.css` 37줄):
     320px 화면에서 좌우 패딩을 제외한 가용 너비는 288px입니다. 로고(약 75px), 햄버거 메뉴 버튼(44px), 좌우 간격(16px)을 제외하면 잔액 버튼에 남는 공간은 약 153px입니다. 영어 환경에서 `Balance $10,000`이거나 표시 통화가 원화(`잔액 ₩13,500,000`)인 경우 텍스트와 패딩(28px)을 합쳐 140-160px를 차지하므로, 288px 가용 폭을 거의 꽉 채우거나 초과하여 로고와 버튼이 서로 밀어내며 찌그러질 위험이 있습니다.
   - **박스 화면 하단 고정 막대 높이 과다** (`web/components/box/BoxScreen.tsx` 199-205줄, `web/app/take.css` 20줄, 화면 `qa/work/melt3/short-1-short-with-items-mobile.png`):
     잔액 부족 시 수량 칩, 주 단추, 안내 힌트(`.v-take-hint`), 충전 링크가 모두 고정 막대에 들어갑니다. 320px 폭에서는 막대 높이가 220px 이상으로 높아져 화면 세로(예: iPhone SE 높이 568-667px)의 35-40% 이상을 차지합니다. 꼬리말 여백(`padding-bottom: 260px`) 처리는 되어 있으나 본문 가시 영역이 좁아집니다.
   - **선택 시트 목록 행** (`web/components/flow/TakeSheet.tsx` 105-110줄, `web/app/ui.css` 370줄):
     `@media (max-width: 359px)`에서 사진 크기가 44px로 축소되고, 상품명 타이틀이 2줄 클램프(`-webkit-line-clamp: 2`) 처리되어 320px에서도 깨짐 없이 배치됩니다.

2. **390px 폭(표준 모바일)**
   - 문제 없습니다. 화면 `qa/work/melt3`의 모바일 스크린샷 전반(375-390px)에서 보관함, 검증, 결과, 선택 시트가 여백 규격에 맞게 안정적으로 렌더링됩니다.

3. **768px 폭(태블릿 세로)**
   - **시트의 창 형태 전환** (`web/app/ui.css` 123-129줄):
     768px부터 `.v-scrim`이 중앙 정렬되고 시트가 모달 창(`max-width: 480px; max-height: 88dvh; border-radius: var(--v-r-card);`)으로 바뀝니다. DESIGN.md 3장의 모달 규칙에 부합합니다.
   - **메뉴가 접힌 상태 유지**:
     768px에서도 상단 네비게이션이 펼쳐지지 않고 햄버거 메뉴 버튼이 유지됩니다(아래 2절 참고).

4. **900px 폭(소형 데스크톱 및 태블릿 가로)**
   - 상단 네비게이션이 노출되기 시작하는 기준 폭입니다. 한국어와 중국어는 안정적이나, 영어 환경에서는 폭이 매우 빠듯합니다(아래 2절 참고).

5. **1440px 폭(데스크톱 와이드)**
   - 문제 없습니다. `AppShell.tsx` 61줄에서 결정 화면은 가운데 좁은 열(`.v-main--col`, 최대 560px), 박스 목록 등은 넓은 열(`.v-main--wide`, 최대 1120px)로 정확히 분기되어 중앙 정렬됩니다.

### 2. 머리 메뉴가 접히는 폭을 900 으로 올린 것의 영향

- **근거 파일**: `web/app/ui.css` 40-41줄, `web/components/shell/AppShell.tsx` 50-56줄, `web/messages/v.en.json`
- **검토 내용**:
  1. **768px-899px 태블릿 세로 환경의 영향**:
     기존 768px 이상에서 펼쳐지던 상단 메뉴를 900px 미만에서 햄버거 메뉴(`.v-menu-btn`)로 접음으로써, 768px 폭에서 영문 메뉴 7개가 두 줄로 꺾이던 레이아웃 붕괴는 완전히 해결되었습니다. 다만 태블릿 사용자는 페이지를 이동할 때마다 햄버거 단추를 눌러 모달 창을 띄워야 합니다.
  2. **900px-940px 구간에서 영문(en) 네비게이션 가로 여백 부족 위험**:
     `v.en.json` 기준 7개 메뉴(`All boxes`, `Inventory`, `Wallet`, `Recent results`, `Verify result`, `How it works`, `Account`)의 글자 폭과 패딩(링크당 20px), 간격(4px * 6)의 합은 약 640px입니다. 900px 뷰포트에서 `v-header-in`의 내부 가용 폭은 868px(900px - 32px)입니다. 여기에 로고(약 80px)와 우측 잔액 단추(`Balance $10,000`, 약 130px)를 더하면 총합이 약 850px에 달합니다. 남는 여백이 약 18px에 불과하여, 잔액 자리수가 늘어나거나 시스템 기본 영문 글꼴 폭이 조금만 넓어져도 네비게이션 링크와 잔액 버튼이 충돌하거나 줄바꿈될 위험이 있습니다.
  3. **메뉴 버튼의 접근성 속성 누락**:
     `AppShell.tsx` 56줄의 `<button className="v-headbtn v-menu-btn" onClick={openMenu} aria-label={t("nav.menu")}>`에 `aria-haspopup="dialog"`와 `aria-expanded={menu}`가 없습니다. 시트를 열고 닫는 토글 상태를 스크린 리더가 알 수 없습니다.

### 3. 시트의 포커스 가둠과 닫기

- **근거 파일**: `web/components/ui/Sheet.tsx` 12-51줄, `web/lib/useModal.ts` 44-84줄, `web/components/flow/TakeSheet.tsx` 90, 125, 128줄
- **검토 내용**:
  1. **포커스 가둠(Focus Trap)과 닫기 동작**:
     `useModal.ts`에서 Tab과 Shift+Tab 키를 감지하여 다이얼로그 내부의 첫 요소와 마지막 요소 사이를 순환하도록 포커스를 정상 가둡니다. Esc 키 입력 시 `onClose()` 호출과 이벤트 전파 중단(`stopImmediatePropagation`), 배경(스크림) 클릭 닫기, 모달 종료 시 이전 활성 요소로 포커스 복귀(`fallback`)가 모두 안정적으로 동작합니다.
  2. **TakeSheet의 단계 전환 포커스 흐름**:
     `TakeSheet.tsx`에서 선택(`pick`)에서 확인(`confirm`), 완료(`result`)로 넘어갈 때 각각 독립된 `Sheet`와 `Confirm`이 마운트됩니다. 각 단계가 열릴 때마다 `useModal`이 패널(`panel.focus()`)로 포커스를 다시 가져오므로 포커스가 외부로 유실되지 않습니다.
  3. **Confirm 컴포넌트의 초기 포커스 위치**:
     `Sheet.tsx` 38줄에서 `role="alertdialog"`로 정의된 `Confirm`은 열릴 때 `tabIndex={-1}`이 부여된 컨테이너 패널로 포커스가 이동합니다. 취소 링크나 주 확인 단추로 직접 포커스가 이동하지 않으므로, 키보드 사용자는 Tab 키를 한 번 더 눌러야 첫 버튼에 진입할 수 있습니다.
  4. **정적 제목 ID 중복 잠재 문제**:
     `Sheet.tsx` 18, 22줄에서 `aria-labelledby="v-sheet-title"`, `<h2 id="v-sheet-title">`를 정적으로 사용합니다. 단일 시트 렌더링 시에는 문제없으나, 여러 시트 컴포넌트가 동일 페이지에 존재할 경우 ID 고유성 규칙에 위배될 소지가 있습니다.

### 7. 긴 영어와 중국어 문구의 넘침

- **근거 파일**: `web/components/box/WinsScreen.tsx` 64, 66줄, `web/app/ui.css` 49줄, `web/app/take.css` 15줄, `web/messages/v.en.json`

     `WinsScreen.tsx` 64, 66줄:
     `<span className="v-small v-num">{t("wins.value", { amount: fmt(r.value) })}</span>`

  3. **다국어 버튼 라벨의 길이**:
     `TakeSheet.tsx` 118줄 주 단추의 영문 라벨 `Take USDT (10 items, $1,471.55)`는 약 32자입니다. 320px 화면(버튼 가용 폭 약 240px)에서 글자 크기 16px 기준 약 250px를 차지하므로, 수량이나 금액 자리수가 더 커지면 단추 내부 좌우 패딩(24px * 2)과 겹치거나 두 줄로 꺾일 위험이 있습니다.
