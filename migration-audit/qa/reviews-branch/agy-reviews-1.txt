### 제안 변경 사항 우선순위 목록

#### 1순위. 박스 상세 화면에서 후기 섹션 배치 순서 변경 (위계 정상화)
- **제안 내용**: [`ui.css`](file:///C:/Users/hyun1/dev/VOILA-audit-reviews/web/app/ui.css#L327-L331)의 flex/grid order를 조정하여, 화면 순서를 `헤더 -> 대표 실물 사진(Hero) -> 구성품(Contents) -> 확률 요약(Odds) -> 후기(Reviews) -> 알아둘 것(Notes)` 순서로 변경합니다.
- **기대 효과**: 사용자가 박스에 들어왔을 때 무엇을 받을 수 있는지(구성품)와 확률을 즉시 확인한 뒤, 구매 직전 신뢰 보조 정보로 후기를 탐색할 수 있게 됩니다. 히어로 사진 클릭 시 곧바로 구성품으로 자연스럽게 이어지며, 2,000px 스크롤 장벽이 해소됩니다.
- **회귀 위험**: 상단 헤더의 별점 링크(`v-ratinglink`) 클릭 시 `#reviews`로 스크롤되는 거리가 화면 아래쪽으로 길어집니다. 링크 앵커 동작 자체는 정상 작동합니다.

#### 2순위. 첨부 사진 존재 시 내부 상품 카드의 썸네일 중복 노출 제거
- **제안 내용**: [`BoxReviews.tsx`](file:///C:/Users/hyun1/dev/VOILA-audit-reviews/web/components/box/BoxReviews.tsx#L174-L180)에서 후기에 첨부 사진(`card.photo`)이 있을 경우, 아래 상품 카드([`v-rv-item`](file:///C:/Users/hyun1/dev/VOILA-audit-reviews/web/app/reviews.css#L22)) 내의 작은 썸네일([`v-rv-thumb`](file:///C:/Users/hyun1/dev/VOILA-audit-reviews/web/app/reviews.css#L23)) 렌더링을 생략하거나 글자 위주의 간결한 형태로 전환합니다.
- **기대 효과**: 동일한 카탈로그 이미지가 10px 간격으로 상하 반복 노출되는 기계적 어색함을 해소하고, 사진 후기 행의 세로 높이를 절감하여 목록 밀도를 향상시킵니다.
- **회귀 위험**: 실제 이용자가 등록한 사진과 카탈로그 썸네일 간의 구분이 모호해질 수 있으므로, `card.mine`이 아닐 때만 적용하거나 구조적 분기 조건을 신중히 설정해야 합니다.

#### 3순위. 박스 상세 화면에서의 후기 노출 건수 축소 및 더 보기 동작 분리
- **제안 내용**: 박스 상세 화면([`BoxReviews.tsx`](file:///C:/Users/hyun1/dev/VOILA-audit-reviews/web/components/box/BoxReviews.tsx#L238))에서는 초기 노출 건수를 3~5건으로 줄이고, "후기 더 보기" 버튼을 인라인 20건 추가 대신 "후기 모두 보기"(`/reviews?box=...`) 화면으로의 명확한 유도 경로로 정리합니다.
- **기대 효과**: 박스 상세 페이지의 스크롤 길이를 획기적으로 줄여 핵심 구매 흐름(열기, 구성품 확인)에 집중할 수 있으며, 80~400건의 풍부한 샘플 탐색은 전용 모아보기 화면(`/reviews`)에서 쾌적하게 수행할 수 있습니다.
- **회귀 위험**: 기존에 박스 화면 안에서 곧바로 10건 이상의 후기를 스크롤하려던 사용 흐름이 페이지 이동으로 바뀝니다. `REVIEWS_FIRST` 상수가 [`ReviewsScreen`](file:///C:/Users/hyun1/dev/VOILA-audit-reviews/web/components/box/ReviewsScreen.tsx#L25)과 공유되고 있어 별도 상수로 분리 정의해야 합니다.

#### 4순위. 데스크톱 메인 열의 상품 카드([`v-rv-item`](file:///C:/Users/hyun1/dev/VOILA-audit-reviews/web/app/reviews.css#L22)) 최대 너비 제한
