AGENTS.md와 DESIGN.md, JOURNEY.md를 먼저 읽어라. 코드는 보지 마라. 읽기 전용이다. 파일을 고치지 마라.

EXPERIMENT. 박스 화면 첫 화면 두 안을 실제로 만들어 찍었다(모바일 390x844). 어느 쪽을 쓸지 Claude 는 아직 정하지 않았고 선호도 말하지 않는다. 네가 먼저 고른다.
- A안(carA, watchA): 제목과 "1회 가격, 가장 흔한 결과" 한 줄 → 실물 사진 띠(머리에 실물 전체 확률, 타일마다 값과 확률) → 박스 정보 4행 → 구간별 확률 4행
- B안(carB, watchB): 제목과 같은 한 줄 → 박스 정보 4행 → 기대 가치 설명 → 구간별 확률 4행 → 실물 사진 띠

타깃 사용자 다섯(처음 온 사람, 특정 상품을 원하는 사람, 확률을 따지는 사람, 의심하는 사람, 반복 이용자)마다 어느 안이 왜 나은지 한 줄씩. 그다음 전체 판정 하나(A, B, 또는 둘의 합성안을 구체적으로)와 근거 3문장. "둘 다 괜찮다"는 답은 안 된다. 사용자가 첫 화면에서 5초 안에 무엇을 이해하는지, 희귀한 결과를 보통의 결과로 오해할 위험, 상품을 보고 흥미를 느끼는 힘, 이 셋을 저울에 올려라. 긴 줄표와 가운뎃점 문자, 느낌표는 쓰지 마라.
