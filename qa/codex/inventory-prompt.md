# 조사 범위 (코드 전체를 검색해서 찾는다. 추측하지 않는다)
1. 라우트와 페이지 전부 (app/ 아래, 로케일 포함, 404와 오류 화면 유무)
2. 오버레이 전부: Modal, Dialog, Sheet, Drawer, Popup, Popover, Tooltip, Toast, Snackbar, Alert, Notification, Dropdown, Select, createPortal, alert(, confirm(, prompt(, role="dialog", role="alert", role="status", AnimatePresence 로 띄우는 겹침 화면
3. 상태 전부: 비로그인과 로그인, 잔액 0과 부족과 충분, 로딩, 빈 목록, 실패, 네트워크 끊김, 세션 만료, 첫 방문과 재방문, 입금과 출금 대기, 한 개와 여러 개 개봉, 대량 개봉, 자동 열기, 배송 신청, USDT로 받기(환급), 2단계 인증, 비밀번호 변경, 탈퇴
4. 문자열: i18n 네임스페이스 목록과 키 수, 하드코딩된 문자열이 있는 파일, 서버나 어댑터의 오류 메시지, 알림 문구
5. 서드파티 UI와 라이브러리 기본 스타일(예: QR 코드, confetti, 브라우저 기본 select, 날짜 입력, 스크롤바)
6. 개봉 연출과 관련된 것 전부(룰렛, 니어미스, 승급 반전, 문지기 연출, 대량 개봉 요약, 효과음)
