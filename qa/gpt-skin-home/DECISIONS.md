# VOILA 메인 페이지 시안: TETH 식 화면과 카피 (2026-10-10)

브랜치 `design/gpt-skin-home`, 커밋과 푸시 전 상태. 기준은 TETH 저장소의 `DESIGN_PROMPT.md`와 `ux/spec/UX_COPY_SYSTEM.md`, 진행은 그 문서 7장의 Codex 5단계(s1 분석, s2 구현, s3 픽셀 검수, s4 반영, s5 최종).
Codex 원문은 `CODEX_RAW_s1.md`, `CODEX_RAW_s3.md`, `CODEX_RAW_s5.md`.

## 파운더 지시
- VOILA 디자인을 TETH(ChatGPT처럼 만든 화면)처럼 바꾼다. 카피도 GPT처럼. 우선 메인 페이지만. 시안을 Codex와 함께 뽑는다.

## 정한 것

## 파운더가 정할 것
1. 히어로 제목 "취향에 맞는 박스를 찾습니다"로 갈지. Codex의 다른 후보: "원하는 구성품이 있는 박스를 고릅니다", "구성품과 확률을 확인하고 고릅니다".
2. 추천 박스 갤러리를 메인에서 뺀 것을 유지할지.
3. 푸터의 언어 지원 설명을 "한국어, 영어, 중국어를 지원합니다." 한 줄로 줄일지(전 페이지 공용).
4. 영어와 중국어 문구도 같은 문체로 바꿔 두었음. 원어민 검수는 하지 않음.
